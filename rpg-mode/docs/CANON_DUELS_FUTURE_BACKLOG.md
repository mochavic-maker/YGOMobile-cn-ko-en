# 原著对决还原 · 未来时间轴待办清单（2000+ Backlog）

> **核心设计原则（严格 OCG 本土化 · 全作品保留）**：
> 1. **核心卡定档与 100% 保留原著卡**：每一场原著漫画 / 动画 / 剧场版对决还原均完整保留，从双方原著用卡中挑选代表性的**核心卡（`coreCardIds`）**，并以这些核心卡在**日本 OCG 首次正式发售日期的最大值**作为时间轴解锁日期（`timelineDate`）；一旦解锁，**原著中双方使用过的全部卡牌均尽量 100% 保留（容忍少量非核心未来卡，不轻易剔除原著用卡）**。
> 2. **《决斗者遗产》蓝本适配与事件日期强度补位**：不足 40 张的补位卡优先参考《游戏王：决斗者遗产》Story Deck 战术结构蓝本（`lotdDeckName` + `lotdEraPaddingIds`），并将现代补强替换为事件日期（`timelineDate`）OCG 卡池内的同定位强卡；严格遵守主题纯净度（如 `EXODIA_DRAW` 禁塞场地/装备/自毁弃牌卡）与事件日期攻防基线（严禁落后环境的低攻防非原著凑数白板及敌对角色王牌串场）。
> 3. **双结局分支 AVG 对话场景**：每场迁入 `ocg_canon_duels.json` 的对决均须配置战前开场（`introDialogue`，≥3 句）、正史胜方标记（`canonWinnerSide`: `"A"`/`"B"`）及彼此独立的双分支结局（`outroSideAWin` 与 `outroSideBWin`，均 ≥2 句且含双方台词），确保战后无论胜、负、平局皆自动路由对应结局对话。
>
> 当延长时间轴至新一年/新期（如 2000 年 Series 2 / DM TV 动画开播起）时，**必须优先核查本清单**，将目标解锁日期落入新时间轴区间的对决还原迁移至 `rpg-mode/src/main/assets/rpg/ocg_canon_duels.json` 并从本清单标记为已合入。
